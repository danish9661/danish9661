## Hi, I'm Danish

I'm an engineer who ships across **Embedded Systems**, **IoT**, and **Machine Learning**. My work spans two worlds: one day I'm writing low-level firmware for ESP32 or STM32, and the next I'm implementing DSP pipelines and ML models. The throughline is the same — bridging the gap between physical hardware and intelligent software to build performant, connected systems.

- **Currently building** → [OpenHW-Studio](https://github.com/OpenHW-Studio) & [STM32-Bluepill-emu](https://github.com/danish9661/STM32-Bluepill-emu)
- **Interests** → Wi-Fi & BLE Stacks, IoT Firmware
- **Gravitate toward** → Building tools and hardware abstractions that make complex systems easier to use
- **Open to** → Collaborations on embedded ML, IoT platforms, and open-source hardware tools

## How I think about building

Whether it's writing close-to-the-metal C++ for an ESP32 or structuring a data pipeline:

> **1.** Understand the constraints (memory, power, time) → **2.** Build a robust foundation → **3.** Iterate with real data → **4.** Optimize for performance and reliability

*Keep it simple, make it reliable.*
